## Project Overview
AutoHotkey v2 GUI for managing World of Warcraft characters across multiple profiles.
All INI files live in `.\ini\` relative to the script.

---

## Confirmed Design Decisions

### General
- AHK v2.0 required
- Fixed-width font: `Courier New` — defined as `FIXED_FONT := "Courier New"` constant near top of script
- Status bar: always visible, full width, bottom of GUI, auto-height, left-aligned. Default text: "Ready"
- Window title: "Character Manager" (standard title bar — no custom title bar for now)
- GUI dimensions: auto-determined by content; no manual resizing needed
- `Escape` key exits the app (already in current script)
- No Undo feature anywhere in the project

### Tab Structure
Three visible tabs: **View | Edit | Profile**
One hidden/dynamic tab: **ACD (Add/Change/Delete)** — surfaces automatically when any `[+] [@] [!]` button is clicked; no clickable tab header

---

## VIEW Tab
- **Controls:** Profile DDL + Character DDL (only interactive controls)
- **All other fields:** read-only Text labels
- **Field order (left label : right value):**
  Profile | Character Name | Level | Gender | Guild | Realm | Faction | Race | Class | Specialization | Armor Type | Profession 1 | Profession 2 | Profession 3 | Profession 4 | Profession 5 | Online Profile
- **Online Profile:** right-column Text control styled as hyperlink (blue, underlined); left label reads "Online Profile:"; clicking opens Blizzard URL in default browser; URL format from `characterdata.ini` template
- **Guild field hover tooltip:** shows full guild data string `GuildName:Realm:Faction:GuildLeader` from `[Guild Names]` → `data=` in characterdata.ini; if the currently viewed character IS the guild leader, append ` [*]` notation
- **Character Name DDL hover tooltip:** shows full character name (in case truncated)
- **Buttons:** `[Close]` only (exits script)
- **No `[+] [@] [!]` buttons on View tab**
- Guild hover tooltip appears on **every tab** that displays a Guild name

---

## EDIT Tab
- Same field layout and order as View tab
- All fields fully editable
- Pre-populated with selected character's data when switching to Edit tab
- **Cascade behavior:** Faction → Race → Class → Specialization; Class selection preserves Armor Type
- **Realm field:** typeahead/autocomplete — Edit control + filtered ListView updated on each keystroke; sourced from `staticdata.ini [realms]` → `realm=` values; positionally paired with `realmurl=` values by index
- **Level field:** free-entry with validation (numeric, 1–90)
- **Gender field:** DDL from `staticdata.ini [genders]`
- **Guild field:** DDL from `[Guild Names]` in characterdata.ini
- **Profession fields:** 5 separate rows, same as View tab
- **Buttons:** `[Save]` and `[Cancel]` — both disabled until any field change is made (even if reverted to original value, buttons remain enabled)
- **Cancel:** prompts confirmation if any unsaved changes exist
- **Switching characters with unsaved changes:** warns user before proceeding
- **`[+] [@] [!]` buttons** appear next to:
  - Character Name: `[@]` only
  - Guild: `[+] [@] [!]`
  - Guild Leader: `[+] [@] [!]`
  - Realm: `[@]` only
  - Profile: `[@]` only
- **New character via Profile tab:** when a character is added on Profile/ACD tab and saved, Edit tab opens with Profile and Character Name pre-filled; all other fields blank

---

## PROFILE Tab
- Uses the same `[+] [@] [!]` button pattern
- Layout mirrors the ACD tab (see below)
- Operations for **Profiles:** Add / Rename / Remove
- Operations for **Characters within a profile:** Add / Rename / Remove
- On Remove Profile: remove profile name from `[Profile Names]` in characterdata.ini AND from `[Profiles]` in profiledata.ini; rename orphaned character sections to `[Orphaned - CharacterName]` and move them to the bottom of profiledata.ini in chronological order (oldest → newest); leave character data sections intact in characterdata.ini

---

## ACD (Add/Change/Delete) Tab — Hidden/Dynamic
Surfaces when any `[+] [@] [!]` is clicked anywhere in the GUI. Replaces/switches to ACD tab visually. Returns to originating tab when done.

### Layout
```
:*: Add / Change / Delete :*:

Profile:      [field]      [+] [@] [!]   *
Character:    [field]      [+] [@] [!]   *
Realm:        [field]      [+] [@] [!]   **
Guild:        [field]      [+] [@] [!]   *
Guild Leader: [field]      [+] [@] [!]   ***

                           [Save]  [Cancel]

Legend: [+] add  [@] change  [!] remove
```
Legend displays in status bar while ACD tab is active; reverts to "Ready" when closed.

### Field behavior
- Always show all 5 rows; irrelevant rows grayed out based on context
- `[+]` replaces field content with empty edit field
- `[@]` replaces field content with editable field pre-filled with current value
- `[!]` prompts MsgBox confirmation showing exactly what will be deleted
- All changes tracked in memory; nothing written to INI until user accepts via `[Save]`
- `[Cancel]` reverts all pending changes; prompts confirmation if changes exist
- `[Save]` and `[Cancel]` right-aligned

### Field notes
- `(*)` DDL with data from profiledata.ini
- `(**)` Live typeahead edit field from staticdata.ini (same as Edit tab Realm control)
- `(***)` DDL including the character name entered above (even if unsaved), alphabetized; includes "--new profile--" option at top when adding a new character as guild leader
- `[@]` on Realm activates/focuses the typeahead field

### Guild Leader — new character flow
- Selecting "--new profile--" from Guild Leader DDL prompts for Profile association
- New character written as minimal stub to characterdata.ini:
  ```ini
  [NewCharName]
  character name=NewCharName
  ```
  All other fields blank; fleshed out later via Edit tab

### Rename cascade
- Renaming a character updates: INI section header `[OldName]` → `[NewName]`, `character name=` key, and any references in `[Guild Names]` → `leader=` if that character is a guild leader
- All cascading updates tracked and confirmed before any write to INI files

---

## Edit Field Color Feedback (background shading)
Applies to all free-entry name fields (Character Name, Guild Name):
- **Red:** below minimum length (< 2 chars) — not yet valid
- **Light green:** valid and comfortable
- **Light yellow:** getting close to maximum
- **Light red:** at or beyond maximum length
- Thresholds:
  - Character name: min=2, max=12; yellow zone = 10–11; red zone = 12
  - Guild name: min=2, max=24; yellow zone = 21–22; red zone = 24 (note: "Random Acts of Rodenticide" is grandfathered at 26+spaces)
- Color constants defined near top of script for easy editing
- Font: Courier New for all edit fields subject to color feedback

---

## INI / Data Notes
- `A_UserName` used at startup to look up profiles from `profiledata.ini [Profiles]`
- All profiles belong to the current Windows user; no multi-user login support
- Realm display names and URL-safe names paired positionally by index from `staticdata.ini [realms]`
- Guild data string format: `GuildName:Realm:Faction:GuildLeader`
- Only write to INI files after user explicitly confirms/saves
