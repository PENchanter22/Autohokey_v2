## Project Overview
AutoHotkey v2 GUI for managing World of Warcraft characters across multiple profiles.
All INI files live in '.\ini\' relative to the script.

---

### General
- AHK v2.0 required
- Image logo centered at the top, already included*
- Custom 'title' text, centered, already included*
- An image used to 'underline' the 'title' text
- 3-Tab gui (see below)
- Status bar: always visible, full width, bottom of GUI, "r1" [see "SUGGESTION:" below], left-aligned. Font: "Arial Rounded MT Bold", size = "10"; Default text: "Ready." ; Changing the statusbar text should be handled by its own function
- [TAB] key can be used to navigate the interactable elements, including TABs: one-by-one, left-to-right, top-to-bottom
- Fixed-width, bolded, font used for all 'Edit' fields: "Courier New", size "12"
- I would prefer the GUI dimensions to be auto-determined by overall content, no manual resizing will be needed, but if it would be better to configure exact values, this will take a lot of trial-n-error
- [ESCape] key exits the app
(*) ... in provided script (see "Script:" above)

	"Also, for all types of [GUI] controls, specifying the number of rows via the 'R' option is usually preferable to using 'H' because it prevents a control from showing partial/incomplete rows of text."

### Tab Structure
Three visible tabs appear below the 'title' + 'underline': Viewer,  Editor,  Manager

## The Viewer tab has two columns,
	Column A) a ("Bold") text list of: Profile, Character, Realm, Guild, Level, Gender, Faction, Race, Class, Specialization, Armor Type, Profession 1?5, Online Profile

		- If no profiles are found, the user is switched to the "Manager" tab with status bar text: profile data not found!
	Column B) all fields begin 'empty' until a character is selected.
		to the right of each field name text (from the list above), omitting "Online Profile" and "Armor Type" rows, will have a dropdown list (DDL) with values populated from saved character data found in <characterdata.ini>
	+ If no character name or other data is found, the user is switched to the "Manager" tab with status bar text: character data not found!
	+ Add a [@] button after the following (DDL) fields: Profile, Character, Realm, Guild
		then change the status bar text to: Legend: [@] change
		Clicking on this button swaps to the "Manager" tab**
	+ "Online Profile" row has a hyperlink (right column), which should appear as a standard hyperlink, labeled: View <character name's> Profile
	+ "Guild" field hover 'tooltip' shows full guild data string 'GuildName:Realm:Faction:GuildLeader' from '[Guild Names]' → 'data=' in characterdata.ini, one value per line
	+ If the currently viewed character is also the currently viewed guild name's "leader", then add an ORANGE '[space]star'*** to "Guild:" text (left column)*** e.g.: Guild *:
